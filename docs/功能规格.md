# 功能规格 — harness-textrpg（西游记章回文字冒险）

> 描述对象 = 当前代码实况（backend/src/text_rpg/ + data/chapters/ + frontend/src/）。
> 每条验收标准均点名真实测试用例或可观测行为，无愿景条目。
> 内容量：3 章回 / 12 把锁 / 4 个结局；后端 52 个测试函数（含 12 锚 ×2 参数化，共 74 例）；前端 15 例。

数据全景：

| 章 | 标题 | 锁 | 场景 | 结局 |
|---|---|---|---|---|
| ch01 | 第一回 两界山前 | 3 | s01_village / s01_woodcutter_hut / s01_temple / s01_foothill / s01_cliff | turned_back 半途折返（mid_chapter） |
| ch02 | 第二回 三打白骨精 | 4 | s02_first_meet / s02_after_first / s02_second_meet / s02_after_second / s02_third_meet / s02_exposed | banished_early 被逐早终（mid_chapter） |
| ch03 | 第三回 火焰山 | 5 | s03_approach / s03_cave_door / s03_plea / s03_snatch / s03_pass_gate / s03_summit | true_form 现形归真 / west_won 借扇西行 |

开局（data/game-start.json）：`attributes: {insight: 1}`，`backpack: []`。

## 二、API

端点真源 = `backend/src/text_rpg/routes.py`；错误形状：未知 game id → 404，未知 scene/choice、终局后提交、空名号 → 400，非字符串名号 → pydantic 422。会话库 = 内存 dict（`persistence.py`），服务进程生命周期即会话生命周期。

| # | 端点 | 验收标准（可测） |

| A3 | POST /api/games → 201 `{id,state}`；空/纯空白名 → 400 detail「player_name 必填且不能为空白」（非字符串名 → 422 属错误形状，见上表前说明，无测试断言） | `test_api.py::test_create_game_201_and_empty_name_400` |

## 三、前端四态

顶层视图机 = `frontend/src/App.tsx`（setup → explore → ending；探索期 2s 轮询读局侦测终局；探索态遇 api 404 回建局态）。

| # | 态 | 行为 | 验收标准（可测） |
|---|---|---|---|
| F1 | 建局态（SetupView） | 输入名号 → 开始；空名号按钮 disabled 不发请求；建局失败错误就地呈现 | `frontend/src/__tests__/setup.test.tsx` 三例：createGame 收到「悟空」并进探索视图 / 空名号不发起请求 / 失败文案可见不进探索 |
| F2 | 探索态（JourneyView） | 未锁抉择可点提交；锁抉择 disabled + 挂「锁」徽标，点击弹条件明细面板（缺失 type/key/have/need + 后端 denial 文案）；会话失效 404 → 回建局态回调 | `journey.test.tsx` 四例：可点击提交 / 锁抉择灰显挂徽标 / 明细面板展示缺失与 denial / api 404 回建局态 |
| F3 | 解锁高亮 | 提交响应 unlocked_locks 非空 → 对应抉择（本轮 locked → 未锁差集定位）挂「解锁」徽标高亮 1.5s；新提交清上一轮 timer；组件卸载清 timer | `unlock.test.tsx` 四例：非空高亮 1.5s 消退 / 空无高亮 / 新抉择清理旧 timer / 卸载清理 |
| F4 | 结局图态（EndingView） | 每结局一卡：本局 satisfied 或跨局已见证（localStorage 键 `htextrpg-endings`）→ 点亮「已见证」；未达卡挂缺失条件链；「再入轮回」回建局态；localStorage 读失败 → 页面照常渲染全灰不回写 | `ending.test.tsx` 四例：终局渲染点亮并写 localStorage / 跨局合并两枚点亮 / 未达卡渲染缺失链不点亮 / 读 throw 全灰照常渲染 |
